# stock — S&P 500 초과수익 모멘텀 포트폴리오

S&P 500 지수(SPY)의 수익률을 이기는 것을 목표로 하는 퀀트 포트폴리오 전략과 백테스트 도구입니다.

## 전략 개요

학술적으로 초과수익이 가장 잘 입증된 **모멘텀 팩터**(Jegadeesh & Titman 1993, Antonacci Dual Momentum)를 기반으로 합니다.

1. **횡단면 모멘텀 (종목 선택)** — 매월 말, S&P 500 구성종목의 **12-1 모멘텀**(최근 1개월을 제외한 과거 12개월 수익률)을 계산해 상위 20종목을 동일비중으로 보유합니다. 최근 1개월을 제외하는 것은 단기 반전 효과를 피하기 위함입니다.
2. **절대 모멘텀 (시장 국면 필터)** — SPY의 과거 12개월 수익률이 음수이면 하락 국면으로 판단하고 전량 중기채 ETF(IEF)로 회피합니다. 초과수익의 상당 부분은 폭락장을 피해 **최대낙폭(MDD)을 줄이는 데서** 나옵니다.
3. **거래비용 반영** — 리밸런싱 시 비중 변화량에 편도 10bp(기본값)의 비용을 차감해 현실적인 성과를 측정합니다.

## 설치 및 실행

```bash
pip install -r requirements.txt

# 기본 실행: 2015년부터 현재까지, 상위 20종목, 비용 10bp
python main.py

# 옵션 예시
python main.py --start 2010-01-01 --top-n 30 --cost-bps 15 --defensive SHY
python main.py --no-regime-filter   # 절대 모멘텀 필터 끄기
```

실행하면:
- S&P 500 구성종목을 Wikipedia에서 자동 수집 (실패 시 내장 대형주 목록 사용)
- Yahoo Finance에서 수정주가 다운로드 (`data_cache/`에 캐시)
- 백테스트 후 성과 요약표 출력, `output/summary.csv`와 `output/performance.png` 저장
- 최신 리밸런싱 기준 보유 종목과 비중 출력

## 성과 지표

전략과 SPY를 다음 지표로 비교합니다: **CAGR**(연복리 수익률), **연변동성**, **샤프비율**, **MDD**(최대낙폭), **알파/베타**(CAPM 회귀).

## 프로젝트 구조

```
portfolio/
  data.py       # S&P 500 유니버스 수집, 가격 다운로드 + 캐시
  strategy.py   # 12-1 모멘텀 점수, 종목 선택, 시장 국면 필터
  backtest.py   # 월별 리밸런싱 백테스트 엔진 (거래비용 반영)
  metrics.py    # CAGR, 샤프, MDD, 알파/베타 등 성과 지표
main.py         # 실행 스크립트 (CLI)
tests/          # 합성 데이터 기반 로직 검증 (네트워크 불필요)
```

## 테스트

```bash
python -m pytest tests/ -v
```

네트워크 없이 합성 데이터로 전략 로직(모멘텀 랭킹, 국면 전환, 비용 차감, 지표 계산)을 검증합니다.

## 한계와 유의사항

- **과거 성과가 미래를 보장하지 않습니다.** 모멘텀 전략은 장기적으로 초과수익 근거가 강하지만, 급반등장(예: 2009, 2020년 3월 이후)에서 시장에 뒤처질 수 있습니다.
- 현재 시점의 S&P 500 구성종목을 과거에도 사용하므로 **생존 편향**이 존재합니다. 실제 초과수익은 백테스트보다 낮을 수 있습니다.
- 세금, 슬리피지, 배당 재투자 시점 차이는 단순화되어 있습니다.
- 이 저장소는 투자 자문이 아닌 연구/교육 목적입니다.
